# Raiz

Raiz is a Bible app — read Scripture in a continuous scroll, highlight and
annotate verses, keep a free-form journal, chat with a guide about what
you're reading, and follow guided devotionals and prayer.

Built with Next.js (App Router), Tailwind CSS, and shadcn/ui.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.
